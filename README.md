# Flexus-Cannon

A modular gameplay prototype focused on custom projectile physics, weapon architecture, and event-driven gameplay systems.

The project includes:
- modular weapon and utility systems
- custom projectile physics simulation
- ricochet and collision handling
- projectile pooling
- render texture surface painting
- gameplay feedback architecture
- trajectory prediction
- custom tick/update system
- runtime-configurable modules using ScriptableObjects
